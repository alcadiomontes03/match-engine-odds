# Pulsematch v5.5

**Status (2026-10-02): paper mode, CLV gate closed.**

v5.5 keeps the v5 market-anchored model in `pipeline/v5` exactly as it is (same maths, same gate) and changes how it is run each week: a small pipeline of agents, with an independent read-only Checker that can block anything from being published. The agent code is kept private and is not in this repository; this file documents what it does.

Leagues: Premier League, La Liga, Bundesliga, Ligue 1.

## The agents

| Agent | What it does |
|---|---|
| Orchestrator | Runs the agents in order with time budgets (10 minutes per stage, 30 minutes total) and stops at the first hard failure |
| Data collector | Takes stock of every file in `data/fd` and the odds capture in `data/odds` and `state/`. Proves completed seasons are complete (expected matches = teams x (teams - 1), so Ligue 1's switch from 20 to 18 teams is handled; the abandoned 2019-20 Ligue 1 season is a known exception) and that the capture is fresh. Read-only |
| Market pricer | For each upcoming fixture, takes DraftKings' latest prices and uses `pipeline/v5/market.py` to get the fair 1X2 (Shin), the main total line, expected goals, and fair totals, spreads and BTTS. With no total line it prices the fair 1X2 only |
| Model runner | Builds the paper-pick ledger and CLV with `pipeline/v5/paper_picks.py`, limited to the four leagues, reads the gate from `pipeline/v5/out/backtest.json`, keeps the blend weight at 0 while the gate is closed, and never adds a stake |
| Checker | Read-only. Checks history (complete seasons, no duplicates, dates parse, nothing shrank since the last publish), rating bounds, priced markets (probabilities sum to 1, overround 1.00-1.15, expected goals 0.2-4.5) and the gate (recomputed independently from the picks; no stakes while closed; paper mode; in-scope leagues only). Verdict: PASS, WARN or BLOCK |
| Publisher | Only after PASS or WARN: builds the dashboard's `state/v5` document with `pipeline/v5/dashboard_doc.py` from that run's outputs. After the publish succeeds it records the history row counts as the baseline the next run is checked against |

Principles: deterministic maths stays in `pipeline/v5` and the agents only call it; each agent writes only its own files, with a manifest that hashes them; agents hand work to each other through files; nothing an agent does writes into this repository.

## Stop policy

- Data collector FAILED (no usable history) -> the run stops.
- Data collector OK or PARTIAL -> the run continues; the Checker blocks unusable data.
- Any stage that crashes or overruns its time budget -> the run stops.
- Checker BLOCK, or a Checker that crashed -> nothing is published; the previous dashboard state stays up.
- Checker PASS or WARN -> the run is published.

## Schedule

One weekly run, Mondays after the DraftKings odds pull, first run 2026-10-05. It rebuilds the v5 backtest (`build_dataset.py`, `backtest.py`, `checks.py`) before running the agents, so the gate reading stays current.

## Tests

60 automated tests. Many replay failures that really happened in this project: a season that loaded 63 of 380 matches, a draw parameter of -0.485, a team rating of -13.88, probabilities summing to 1.04, a stake on a closed gate, a gate claimed open without evidence, picks from a league that is not modelled. Others check the pricing: given DraftKings-style prices built from known expected goals (1.6 and 1.1), the pricer recovers 1.611 and 1.091, and a deliberately mispriced spread becomes a paper pick with positive CLV.

## Findings while building v5.5

- Only moneyline prices have been captured so far (222 rows, last pull 2026-09-20). The v5 paper-pick method needs DraftKings' totals line, so it has not had data yet. The capture was switched to moneyline, spreads and totals on 2026-09-25; the first pull with them is expected on 2026-10-05.
- No Bundesliga or Ligue 1 odds have been captured yet (they were added on 2026-09-24, after the last pull).
- `pipeline/v5/paper_picks.py` does not filter by league; the snapshots still contain old EFL Championship captures. The Model runner filters to the four leagues.
- History check (2026-10-02): 40 season files, 12,891 matches, no incomplete completed season.

## Results (unchanged from v5)

Walk-forward 2020-21 to 2025-26, four leagues, 8,454 matches: in every season the adjustment model shrank fully to zero, so v5 equals the market and places no backtest bets. Gate: closed. The ratings-only approach (v4) had mean CLV of -4.0% over 14,415 paper bets. See `pipeline/v5/README.md` for the full table.
