# v8 fixes research (2026-11-11)

Exploration only. Nothing here prices a bet, writes to the dashboard or touches a registered test. Code:
`fixes.py`; results: `out/fixes_summary.md` (the per-match rows file, about 12 MB, is regenerated by
`python3 pipeline/v8/fixes.py` in a few minutes and is not committed).

Three fixes to the frozen v7/v8 rating method, from the 2026-11-11 weak-spots review, with every constant fixed
before the first run (see the docstring in `fixes.py`):

- **nnls**: shot proxy weights kept at or above zero. The live fit's off-target weight was negative in every fold
  (median −0.020). On its own it changes nothing measurable.
- **prom**: newly promoted teams pulled toward the level of last season's relegated teams, fading with their own
  matches (strength P = 5 or 20, fade k = 10).
- **stretch**: the strength difference between the two sides multiplied by s, fitted walk-forward on earlier
  out-of-sample matches. Fitted s settled at about 1.11–1.13, i.e. the market's gaps are about 12% wider.

## Result (walk-forward, 4,506 matches, Aug 2023 – Nov 2026, closing price Shin)

| | Gap to market | Change vs live | 95% |
|---|---|---|---|
| Live v8 method | +0.0221 | | |
| nnls + prom5 + stretch (best) | +0.0202 | −0.0019 | −0.0036 to −0.0002 |

- Promoted-team matches: gap +0.0267 → +0.0212. Heavy favourites (market 71.1%): model 64.5% → 66.9%.
- Better in La Liga, the Bundesliga and Ligue 1; slightly worse in the Premier League. Premier League promoted
  sides were close to the relegated level in some seasons and well above it in others (2025-26), so the prior helps
  in some years and hurts in others.
- 2026-27 so far: gap +0.0162 → +0.0110 (390 matches; promoted-team matches +0.0175 → +0.0076).

## Reading
A real but small improvement: about a tenth of the gap. Eight variants were tried and the best one's interval only
just clears zero, so treat the size with caution. None of this moves the model near the market, and none of it
changes a price (blend weight 0). Adopting it changes the frozen method in `docs/prereg-forward-2026-11.md`, so it
needs a new registration with a new sample start; no sample match has been played yet (international break), so
doing it before the first match after the break loses nothing.
